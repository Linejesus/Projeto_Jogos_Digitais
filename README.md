# Projeto_Jogos_Digitais

O Office Simulation é um jogo educativo em realidade virtual no qual dois jogadores assumem o papel de profissionais de uma empresa de tecnologia. Por meio da exploração de um escritório virtual, os participantes precisam analisar situações, manipular elementos lógicos e solucionar desafios utilizando comunicação, raciocínio lógico e trabalho em equipe. O jogo possui uma proposta cooperativa, na qual cada jogador assume responsabilidades diferentes, tornando a colaboração essencial para concluir as fases dentro do tempo disponível.
